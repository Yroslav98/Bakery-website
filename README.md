# Bakery Training Website

This is my training project for a bakery website. Through this project, I gained hands-on experience in several key areas of front-end development:

## Key Learning Points:
- **Responsive Design**: Learned how to create adaptive layouts that work seamlessly across various devices and screen sizes.
- **SASS**: Mastered the use of SASS (Syntactically Awesome Style Sheets) to write more efficient and maintainable CSS.
- **BEM Methodology**: Implemented BEM (Block, Element, Modifier) methodology to structure CSS classes for better scalability and readability.
- **Mobile-First & Desktop-First Strategies**: Explored and practiced both Mobile-First and Desktop-First design approaches, understanding their pros, cons, and best use cases.

## Purpose:
The primary goal of this project was to deepen my understanding of modern web development practices while building a visually appealing and functional website for a bakery. This project reflects my journey in mastering responsive design techniques and improving user experience through thoughtful coding practices.

## Technologies Used:
- HTML5
- CSS3 (with SASS preprocessor)
- BEM methodology
- Responsive design techniques (Media Queries)
